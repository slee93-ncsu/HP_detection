# Results

This folder contains the intermediate model inputs and evaluation results generated by the heat pump detection pipeline.

The results were produced using the Dallas County residential dataset from ResStock 2025 Release 1. The pipeline uses building-level electricity consumption and outdoor air temperature to classify whether a building has a heat pump.

## Results Summary

The soft-voting ensemble achieved the following mean performance across 5-fold cross-validation on the Dallas County development dataset.

| Metric | Mean | Std |
|---|---:|---:|
| Accuracy | 0.918 | 0.012 |
| Precision | 0.859 | 0.018 |
| Recall | 0.828 | 0.045 |
| F1-score | 0.843 | 0.025 |
| ROC-AUC | 0.971 | 0.008 |
| PR-AUC | 0.926 | 0.018 |

These values are provided as reference performance on the development dataset and should not be interpreted as expected performance on utility data.

## Folder Structure

### 1. Model_Inputs

Contains the processed inputs generated from the original building timeseries data.

- `dallas_features_groupA_E.csv`  
  Statistical features generated by `01_build_features.py`. Each row represents one building and contains 102 load- and temperature-related features.

- `dallas_cnn_profiles.csv`  
  Load profiles generated by `02_build_profiles.py`. Each row represents one building and contains four 24-hour profiles: winter weekday, summer weekday, shoulder-season weekday, and peak day.

These files are used as inputs to `03_train_evaluate.py`.

### 2. Evaluation

Contains the outputs from model training and 5-fold cross-validation.

- `metrics_summary.csv`  
  Mean and standard deviation of the ensemble evaluation metrics across the five folds.

- `metrics_per_fold.csv`  
  Evaluation metrics for each individual fold.

- `model_comparison.csv`  
  Performance comparison among Gradient Boosting, MLP, HybridCNN, and the soft-voting ensemble.

- `confusion_matrix.csv`  
  Pooled confusion matrix from the out-of-fold predictions.

- `model_ablation.csv`  
  Performance of different combinations of the three base models.

- `model_correlation.csv`  
  Pairwise correlation among the base-model prediction probabilities.

- `error_overlap.csv`  
  Number of buildings misclassified by one, two, or all three base models.

- `misclassification_by_type.csv`  
  Misclassification results grouped by heating system type.

- `predictions.csv`  
  Building-level out-of-fold prediction probabilities and labels.

- `run_summary.json`  
  Summary of the run configuration, software environment, dataset size, and ensemble performance.

### 3. Feature_Importance

Contains permutation-importance results generated by `04_permutation_importance.py`.

- `permutation_importance.csv`  
  ROC-AUC decrease after shuffling each statistical feature or load-profile input.

- `group_importance.csv`  
  Permutation importance aggregated by statistical feature group.

## Notes

The files in this folder are reference results from the development dataset and are intended to document the analysis workflow and model behavior.

Performance on utility data may differ because of differences in climate, building stock, heat pump prevalence, data resolution, missing data, and other dataset characteristics.

The original sample data format and pipeline documentation are provided separately under `1. Data_Source` and `2. Code`.
